# MVP Scope v0.1.0

## In scope
- Admin authentication
- Organization and brand foundation
- Raffle CRUD
- Participants and entries/tickets
- CSV import
- Validation/rejection of entries
- Immutable close snapshot
- SHA-256 participant snapshot
- Commit/reveal seed
- Deterministic winner selection
- Rehearsal mode
- Real draw
- WebSocket synchronization
- OBS browser display
- Public result page
- Public verification page
- Audit trail
- Automated critical tests

## Explicitly out of scope
YouTube API, Yape integration, OCR, payment gateway, WhatsApp, email automation, billing, subscriptions, custom domains, advanced analytics and AI.
